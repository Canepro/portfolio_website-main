# Projects and case studies

## Reach

Open `/projects`, then select a case-study link.

## Drive

Click the first `main a[href^="/projects/"]`; require `/projects/<slug>` and `main h1`.

## Observable success

Index and case-study screenshots render without overflow or broken visible images. HTTP contracts require every discovered project route and PipelineHealer section/list markup.

## Prerequisites and limits

Only the first project is clicked in the browser. External demos, media playback, and repository destinations are not opened.
